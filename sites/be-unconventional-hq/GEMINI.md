# Workspace Rules

- **Clean up after yourself**: Do not leave any lingering scratch files, `.log` files, temporary Node scripts, or any other temporary artifacts in the workspace at the end of development runs or after resolving issues. Explicitly delete them before completing your task. If a scratch file must be preserved temporarily for your own internal context, store it exclusively in the Antigravity `scratch/` directory within the artifacts folder, never in the project workspace.
- **Strict Routing & Taxonomy Protocol**: Whenever asked to update a route, link, or taxonomy label (e.g., changing "Gaming" to "Games" or updating the "Events" URL), you MUST perform a global codebase search (using grep/ripgrep) for the old slug/label before making changes. Do not assume the user's mentioned files are the only places the link exists (e.g., homepage tiles often use separate components from global navs). After making changes, you MUST run the full local unit test suite (`npm run test`) to ensure no strict string assertions were broken before concluding your task.
