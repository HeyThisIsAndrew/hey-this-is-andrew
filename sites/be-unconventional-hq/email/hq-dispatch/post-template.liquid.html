{% comment %} THE HQ DISPATCH: Kit RSS "Post Template". Where it goes: in a Kit RSS broadcast (digest mode, weekly), select the Post content block, open its Post Template tab, switch to HTML and paste this file. Kit renders it into {{ message_content }} of template.html. First post in the feed = FEATURED (a box with a large 16:9 image). Posts 2 to 6 = LATEST FROM THE HQ (one box per story, 16:9 thumbnail beside the text, stacked on a phone). In single mode Kit passes one post, so only FEATURED renders. Every story sits in the site's box: #111111 (--color-surface) with a 1px #1d1d1d hairline (the site's rgba(255,255,255,0.05), flattened because Outlook ignores rgba), and a red border on hover where hover exists. Section headings are the site's PageTitle lockup: red kicker, heavy uppercase title, and a red "HQ" tucked under it. Kit variables used (all documented by Kit): posts, post.title, post.url, post.summary, post.content, post.categories The label reads " | ", so the feed sends the content type first and the section second ("Review", "TV" renders REVIEW | TV). A "Video" category turns the button into Watch now. Kit has NO documented image variable, so the image is read out of post.content: the feed must put a 1200x675 JPEG as the FIRST element of content:encoded. The contract is in scripts/hq-dispatch.md.
