# Scope boundary: BE Unconventional HQ

BE Unconventional HQ has its own repository. The copy under `sites/be-unconventional-hq/` is outdated and does not contain its latest changes.

Use HQ only as a reference when working on the personal site. Do not modify HQ source or deploy to BE Unconventional HQ unless the user explicitly requests that HQ work. Permission to implement, merge, or deploy the personal site does not authorize any HQ deployment.
