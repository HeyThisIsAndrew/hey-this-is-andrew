## P1 · Restore rotating tile parity

### Verified cause

The desktop cards are far wider than the reference even though their rotation uses the same 1000 px perspective, 180° Y-axis turn, 600 ms duration, and `cubic-bezier(.4, 0, .2, 1)` easing. The closer edge of a wider card projects much farther forward with the same perspective. CCC uses one track at every width and HQ hub uses two at desktop. The live reference uses four desktop tracks. The branch also fades the faces during the turn and offsets them with `translateZ(1px)`. Live faces use backface visibility with border/shadow transitions, without that extra fade or depth offset. [Live reference](https://beunconventionalhq.com/about).

Measured after fonts loaded in Chromium, in CSS pixels. Sizes are untransformed width × height for the first card. The 390 px measurements use the Pixel 5 profile.

| Viewport | Live HQ About | Branch HQ hub | Branch CCC |
| --- | ---: | ---: | ---: |

| 1440 × 900 | 333 × 155 | 671 × 119 | 824 × 121 |
| 3840 × 2160 | 611 × 221 | 1374 × 157 | 2193 × 291 |

At 4K the branch HQ hub card is **2.25×** the reference width and the CCC card is **3.59×**. Live CCC on `main` was already oversized at 1698 px, and the branch widens it another 495 px.
