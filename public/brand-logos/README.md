# Brand logos

Wired into the brand cards via `src/data/brands.ts`:

- `be-unconventional.png` → BE Unconventional HQ card
- `capture-create-caffeinate.png` → Capture Create Caffeinate card

To swap a logo, drop the new file here and update the matching `logoSrc`
in `src/data/brands.ts`. Transparent PNG or SVG, and keep the `fit`
field on `contain` so logos get breathing room inside their frames.
